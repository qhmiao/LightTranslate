# 轻译 · LightTranslate

**选中英文，译文自然浮起；继续操作，浮层自然消失。**

轻译是一个 Windows 桌面划词翻译工具。拖选或双击英文，译文就会出现在鼠标旁。
浮层只显示译文，保留当前应用的输入焦点，让你顺手读完、继续操作。

![轻译浮层预览](assets/preview.png)

## 阅读时少一步

- **选中即译**：拖选、双击选词或使用键盘选择文字，自动显示译文。
- **顺手收起**：点击、打字、滚动页面或切换应用时，浮层自动淡出。
- **单词本地快查**：约 76 万条 ECDICT 词库，支持离线查词，并补充常见编程术语。
- **句子在线翻译**：默认使用微软翻译接口，腾讯接口作为备用；也可明确选择单一服务或自备密钥使用 DeepL 官方 API。
- **留足阅读时间**：鼠标悬停时保持显示，长译文可在浮层内滚动。
- **融入桌面**：圆角、淡入淡出、明暗主题和托盘开关。

## 开始使用

运行环境：Windows 10/11 x64，.NET Framework 4.8。

1. 从 [Releases](https://github.com/qhmiao/LightTranslate/releases) 下载便携包。
2. 解压到固定目录，例如 `%LOCALAPPDATA%\LightTranslate`，双击 `LightTranslate.exe`。
3. 在桌面应用中选中英文，查看鼠标旁的译文。

启动后，系统托盘会出现“译”图标。右键可开关自动翻译、打开设置面板、打开设置文件或退出；
双击图标可直接切换自动翻译。

轻译面向支持复制选区的桌面应用，默认跳过终端和纯中文选区，每次最多选择 2,000 个字符。
当前译文目标为简体中文。

## 按自己的习惯设置

在托盘“译”图标上右键，选择 **设置…**。面板分为“翻译、浮层、启动、DeepL”四页，保存后生效：

- **翻译**：自动划词开关、选区取词开关、在线服务及目标语言、单次选区长度上限、排除应用和最低英文占比。托盘开关会立即生效并同步到已打开的面板；面板中的改动在保存后应用。关闭选区取词后不获取选区。目标语言影响微软和 DeepL；本地词库和腾讯仍输出中文。
- **DeepL**：手动输入 API 密钥，输入遮挡且不回填。留空保留现有密钥，清除需点击“保存”；取消不改变密钥。密钥用 Windows 当前用户 DPAPI 加密，单独存入应用目录的 `deepl-key.bin`，不写入 `settings.json`。换用户或电脑需重新输入。保存设置不联网验证。
- **启动**：读取实际的当前用户启动项，显示当前目录是否开机自启；只有改变选择并保存时才创建或移除启动快捷方式。不写入 `settings.json` 的自启标志，也不默认开启自启。保存失败会显示错误；配置保存失败时会尝试恢复启动项，恢复失败会显示实际状态供检查。

“浮层”页保留以下阅读设置；最低英文占比在“翻译”页：

- **字体和字号**：选择已安装字体，字号范围为 10–48，默认 14。
- **背景色**：留空跟随系统明暗主题，或使用选色器 / `#RRGGBB`；文字颜色自动调整，保持至少 4.5:1 的对比度。
- **自动消失**：默认按译文长度停留 6–22 秒，也可设置 1–120 秒。鼠标悬停时续时；移远、打字、点击外部、滚动外部页面或切换应用仍会提前收起。等待和错误提示保留原来的时长，短停留时间不会提前中断等待中的翻译。
- **最低英文占比**：范围 0–100%。大于 0% 时，A–Z/a–z 字母数占全部 Unicode 文字字母数的比例达到阈值（含等于）才翻译；中文和其他语言字母计入分母，标点、空白、数字、表情及组合音调符号不计入。全角字母和带重音字母计入分母，但不计为 A–Z/a–z。例如 `abc中文` 为 60%，`Hello中文` 约为 71%。

默认 0% 关闭新增比例限制，保留原有的非中文语言过滤（包括原先可翻译的其他语言）；
纯符号、纯数字、空白和纯中文选区仍跳过。大于 0% 时，选区必须含 A–Z/a–z。
这只是字符规则，不是自然语言识别。

保存后配置立即生效并写入应用目录的 `settings.json`；开机自启保存在当前用户启动文件夹。
取消或关闭窗口不会保存配置，也不会改动启动项。
“恢复配置默认值”只恢复面板里的配置输入，保留自启选择，点击保存后才生效；不修改隐藏的诊断开关。
旧配置缺少新字段时沿用原有字体、主题、停留时间和语言过滤。
诊断开关保留为开发排查用的文件配置，不在普通面板中显示。缓存仍为进程内部行为。
排除应用每行一个进程名称，可带或不带 `.exe`，也可用逗号或分号分隔；原有配置未改动的值会保留。例如：

```json
"ExcludedApps": ["SomeApp", "AnotherApp"]
```

开机自启沿用 `startup.ps1` 的当前用户 `LightTranslate.lnk`，无需从面板运行脚本。
指向其他副本的同名启动项、无法读取的状态或 Windows 禁用记录不会被覆盖；面板会提示检查并可刷新。
Windows 已禁用的启动项需在系统启动应用中处理，面板不会更改系统审批或防护设置。
便携目录移动后，应先检查原启动项。

现有命令行脚本仍保留。如需手动创建开机启动项，在解压目录使用 PowerShell 7 运行：

```powershell
pwsh -File .\startup.ps1
```

取消开机启动：

```powershell
pwsh -File .\startup.ps1 -Remove
```

完整配置见 [settings.example.json](settings.example.json)。

## 文字如何处理

默认自动模式先查询本地词库，未命中时发送给微软翻译，失败后尝试腾讯；自动模式不会调用 DeepL。明确选择微软、腾讯或 DeepL 会跳过词库，只请求所选服务，失败不会自动切换。
选择 DeepL 并保存密钥后，选中文字将发送给 DeepL，可能按账户套餐计费；未配置密钥时不请求 DeepL。只使用官方 `POST /v2/translate`，按密钥的 `:fx` 标记选择 `api-free.deepl.com`，其余使用 `api.deepl.com`，不接受自定义地址或 HTTP 重定向。简繁中文对应 `ZH-HANS`、`ZH-HANT`。
额度和费用以 [DeepL 当前 API 套餐](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans) 为准；不内置任何每月免费额度承诺。认证、额度、限流和超时会显示各自提示，不自动重试计费请求。
译文缓存保存在当前进程内，退出后清空。程序默认不记录选区原文或用户译文。
先由独立的 `LightTranslate.SelectionHost.exe` 判断操作区域并读取 Windows UI Automation 文本选区。空选区、图标列表、树等非文本交互直接结束，不访问剪贴板；不会按应用名全局排除资源管理器，列表内重命名编辑框仍可取词。辅助进程限时退出，主程序不持有 UIA/COM 对象。分发或移动程序时请保留该辅助文件。
仅在确认是文本编辑框或文档、但不支持选区接口时，才尝试安全备份、临时复制和恢复剪贴板。图片或应用专用格式导致无法安全备份时不复制，并显示读取失败提示；不清空剪贴板，也不退回 OLE 快照。未知区域或尚未确认文本上下文的探测失败会安静结束并保留固定诊断码，不会发送复制命令；已确认文本区域的读取失败以及辅助程序缺失仍有明确提示。系统或剪贴板管理器仍可能保留实际执行过的临时复制记录。

## 从源码构建

在 Windows 上使用 PowerShell 7 和 .NET Framework 4.8 编译器：

```powershell
git clone https://github.com/qhmiao/LightTranslate.git
cd LightTranslate
pwsh -File .\build.ps1
pwsh -File .\scripts\download-dictionary.ps1
```

构建结果位于 `dist\LightTranslate`。词库下载固定版本，并校验 SHA-256。
配置细节、自检、打包和兼容性记录见 [开发与测试](docs/TESTING.md)。

当前版本：[v0.1.0-alpha.2](https://github.com/qhmiao/LightTranslate/releases/tag/v0.1.0-alpha.2)。
